# Guia de Contribuição

## Estrutura do Projeto

```
├── frontend/      - Aplicação Frontend
├── backend/       - API Backend
├── docs/          - Documentação
└── uploads/       - Arquivos enviados
```

## Setup Local

### Backend
```bash
cd backend
npm install
cp ../.env.example ../.env
npm start
```

### Frontend
```bash
cd frontend
npm install
npm start
```

## Padrões de Código
- Use ES6+
- Mantenha o código limpo e documentado
- Teste antes de fazer commit
- Siga a estrutura de pastas estabelecida

## Commits
Use mensagens descritivas:
- `feat:` para novas funcionalidades
- `fix:` para correções
- `docs:` para documentação
- `refactor:` para refatorações

## Issues
Descreva claramente o problema ou funcionalidade solicitada.
